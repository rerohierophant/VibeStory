# VibeStory 品牌资产

## 标记含义

一条线同时承担两个角色：**分镜框的顶边** 与 **字母 V**。
顶边在中段断开，两侧向下折成 V 的两条臂——正好对应产品最有辨识度的那件事：一段文本被切成一个个镜头框，而每个框仍然属于同一个故事。

- 渐变底 `#d946ef → #7c3aed` 是品牌资产的一部分，固定这四个值，不随界面 token 变化。注意它与 CTA token（`#c026d3 → #6d28d9`）不同：CTA 因为要承载白色小字才收深了一档，Logo 只承载白色描边、不承担正文对比度，保持更亮的品牌色。
- 标记笔画为纯白，保证在渐变底上对比度稳定。
- 圆角 24/96，即 1/4 边长；与 `--vibe-radius-modal` 的观感一致。
- 小尺寸退化：≤24px 时横臂在视觉上消失，只剩 V，仍可辨认（见下方尺寸表）。

## 使用规则

- 不要在标记外包额外的圆角底板；渐变方块本身就是底板。
- 不要旋转、拉伸或改变渐变方向（固定 135°）。
- 不要在马卡龙、高饱和背景上直接使用；`#0D0F11` 深底为佳。
- 标记保留自带渐变底，所以放在白底上依然安全；但圆角方块以外的空白，请留给字标或留白，不要裁切。
