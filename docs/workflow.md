# 创作流程

VibeStory 的工作单位是项目、分集和镜头。页面上的操作和 [前端类型](../apps/web/src/lib/types.ts)是当前交互规格；遇到差异以页面为准。

新建项目或编辑项目风格时，可以在「真人剧」「漫剧」「风格化」中选画面方向。「漫剧」里的手绘童话突出明亮光线和手绘背景；「风格化」里的木版印刷突出分色套印、纸纹和色块。卡片上的图片帮助区分风格；出图使用所选风格的名称、提示和项目风格描述。预设参考图的来源见[素材记录](../design/assets/STYLE_SOURCES.md)。

## 从正文到视频

1. **准备故事。** 新建个人项目后，在项目概览上传 TXT／Markdown 整稿，或输入故事想法并生成分集草案。「只有故事想法」的输入框下方会从 30 条内置灵感中随机展示 3 条，点击卡片会用这条梗概填入输入框，也可点「换一批」浏览其他灵感；编辑好后点「保存想法」。第一步会显示已保存的想法原文，审阅分集草案时可以对照查看。点「编辑想法」可从原文继续修改。生成分集草案时，审阅区会陆续显示模型已输出的内容。草案通过校验后，页面会切换到可确认的分集与素材卡片。可核对每集原文的开头和结尾，或审阅从想法扩写的分集剧本，同时查看建议出图的角色与场景。确认前，可补充分集要求后重新生成，也可以在 Agent 对话里说「规划项目分集：分成三集，保留原来的结局」。点击「确认分集与素材」后才会建立分集及角色、场景条目，已有同名素材会保留。去对应的素材库生成或上传参考图。已有分集的个人项目可展开概览底部的「创作准备」，导入来源并追加分集。团队项目和离线 Demo 可手动新建一集，在「故事」粘贴正文。
2. **拆镜和准备参考素材。** 在「故事」点击「AI 拆解镜头」，到「分镜」编辑描述、景别、运镜、台词与时长。「画面描述 / 台词」栏下方显示这一镜用到的素材，点击缩略图可放大查看当前基准图。先为用到的角色和场景生成或上传参考图。缺图时，分镜页的生成按钮置灰，点击会提示缺哪些图，并提供对应的素材库入口。已有镜头时，「重新拆解」须确认覆盖本集镜头及其分镜图和视频。
3. **出图和确认。** 可逐镜提交，批量出图只可选择参考图齐全的镜头。没有候选图的镜头显示「待出图」。点缩略图可切换展示的画面，点主图可放大并查看候选使用的人物／场景版本。缩略图下方的「确认画面」会将当前展示的候选图设为后续视频的首帧。「删除候选」会移除当前展示的图。删除选定的图后，镜头改为展示最新的剩余候选，需重新确认画面。删完所有候选时，镜头回到「待出图」。已提交的视频任务保留原首帧，生成的视频仍可在「视频」页查看。「状态 / 操作」栏显示镜头的确认状态，可在这里取消确认。「批量确认画面」会先展示本次待确认的画面。
4. **生成视频。** 确认镜头后，切到「视频」页。左侧播放器默认展示当前镜头最新成功生成的视频；还没有视频时可预览首帧。同一镜头成功生成两版或以上后，播放器下方会显示「视频候选」，包括用同一首帧生成的多版视频。点候选可切换预览，并在「镜头详情与首帧来源」查看该版使用的首帧和提示词。切换预览不会改变分镜页选定的首帧。右侧「本集镜头」可切换或按生成状态筛选镜头，「选集」可切换项目分集。单镜生成与重试在预览下方，批量生成在页顶。点击「重新生成」会在预览下方展开编辑区，带入当前预览版本的提示词，并展示分镜页当前选定的首帧。可编辑提示词，也可从下拉选项设置景别和运镜。点击「确认生成」才提交。这些设置只用于本次视频任务，分镜独立保存。分镜表的「计划时长」默认每镜 6 秒，可在镜头编辑中调整节奏。当前 MiniMax 请求 6 秒，Mock 请求 3 秒，视频页按文件实际时长显示成片长度。视频保留提交时选定的首帧，首帧移出分镜候选后，仍可在「镜头详情与首帧来源」中查看。批次有结局只代表每个成员均已结算，成功、失败、未知和阻塞需分别查看。

批量生成分镜图或视频时，在弹窗选好镜头并提交，弹窗立即关闭。页面上的批量生成按钮下方会显示提交状态和批次进度，可展开逐镜明细。提交失败可在页面重试。角色图、场景图、分镜图和视频在排队与生成时共用 V 标记。淡紫高光沿笔画从左到右扫过，排队时更慢、更暗。开启系统的「减少动态效果」时，V 标记静止。等待首个可播放视频时，预览区还会显示首帧缩略图。生成新版期间，状态显示在播放器左上角，仍可切换和播放已生成的候选。也可以在 Agent 对话里询问本集下一步。

在项目左侧切换分集时，已有镜头的分集默认打开「分镜」，还没有镜头的分集进入「故事」，便于填写正文或拆解镜头。每集右侧的「⋯」菜单可以修改集名或删除分集。「修改集名」会在原位显示输入框，分集卡片上的改名按钮也一样。按回车或点到别处保存，按 Esc 取消。确认删除后，本集的剧本、镜头、分镜图和视频会一并移除。删除正在查看的分集后会返回分集列表。

侧栏分集进度以已保存的镜头为准。拆解任务进行时显示「拆解中」。分镜全部确认后显示「待生成视频」，已有部分视频时显示已生成数和镜头总数，每镜都有视频时显示「视频已生成」。修改正文后，已有镜头仍计入进度。

项目列表和项目概览默认使用第一张可用的分镜图作为封面。按集号和镜号查找，同一镜头优先使用当前选定的图。项目还没出图时显示「暂无封面」。

首次出图前，可在项目概览点击当前风格名，调整画面预设和风格描述。已有分集、镜头、素材条目或手动上传的参考图时仍可切换。任意分镜图、角色图或场景图生成成功后，或有图片任务正在排队、生成或结果未知时，风格名仅供查看。生成失败且尚未出图时仍可换风格，下一次生成会按新风格提交。

项目概览页头显示分集数、镜头数和已确认镜头数。项目概览在分集和创作准备上方显示「故事简介」。宽窗口中，故事简介与分集同列，角色库和场景库在右侧。没有项目简介时，概览会显示带来源链接的剧本、分集梗概或分镜节选。新项目有故事内容后才显示这个区域。

工作台左栏的「资产库」显示角色、场景和个人创作配方的合计。资产库页面顶部有「角色」「场景」「创作配方」三个标签页，各自显示数量。总数和分项为 0 时也会显示。角色和场景以大图展示各项目的当前基准图，点击卡片底部的项目名称或「打开项目」可进入所属项目。创作配方页汇总个人配方。资产库右侧的 Agent 对话默认收起，点击星标即可展开。项目概览的角色库和场景库卡片各预览最多 3 个资产的当前基准图。点击「查看全部」进入对应的库，生成、上传或切换基准图。

项目角色库和场景库在桌面端默认展开右侧对话时每行显示三张卡片，内容区较窄时减少列数。角色卡片左侧完整展示全身图，右侧显示描述、版本缩略图和操作。场景卡片使用横图。首次点击「生成一版」后，卡片预览区显示动效以及提交、排队或生成状态，出图后自动显示基准图。点击「上传角色图」或「上传场景图」，上传的图片会立即成为该素材的基准图。版本历史用高亮边框标出当前基准图，点击缩略图可切换；生成的图片标为「生成图」。后续分镜生成读取提交时选中的基准图。

## Agent 对话

右侧对话会边接收边显示 Agent 回复。需要等待的创作或媒体任务会继续更新进度，刷新后可从会话历史查看已提交的消息和任务结果。

个人项目默认展开右侧 Agent 对话，可用边缘箭头收起，再点击对话图标或箭头展开。可以先在对话里发起拆镜，通过对话或分镜页提交出图，审阅分镜图后再确认镜头。页面和 Agent 从同一任务与批次读取进度；切换集、正文或镜头版本后，旧授权和草稿受服务端范围与版本校验。

在右侧 Agent 对话里说「帮我做个雨夜悬疑主题的短剧」，会新建个人项目、保存故事想法并提交分集规划。对话会显示规划进度。草案就绪后，点「前往项目概览审阅」查看分集剧本、角色与场景，再决定是否确认。

点击对话标题旁的「历史会话」，可在标题下方浏览本项目的会话，当前消息和输入框保持显示。分集会话显示为「第 2 集 · 对话名称」，未关联分集的项目会话标为「项目会话」。选中另一集的历史会话时，工作台会一并打开对应分集。

在个人项目的分集对话里，可以说「整理本集剧本」「规划本集分镜」，或「先整理本集剧本，然后规划分镜」。主 Agent 派发对应子 Agent，对话的执行记录显示派发和接收结果。完整草案通过分集创作 API 读取。确认当前分镜草案且本集没有镜头或拆镜任务时，可发送「应用分镜草案」并附上草案 ID。Codex 中的独立 MCP 入口见 [README](../README.md#架构与工程)。

## 图片纠正、偏好与配方

分镜已有图片时，点击「再生成一版」会打开镜头编辑侧边栏。可以直接修改画面描述和镜头参数，再点「生成新候选」。系统先保存编辑，默认按当前设定出图。个人项目可以在「更多出图设置」里选择历史生成设定、填写补充说明或应用配方。角色和场景从各自卡片的「再生成一版」弹窗出图。生成完成后，在原页面比较和选择新候选。

角色和场景的生成弹窗提供「上传参考图」。上传的图会随本次生成任务保存，生成结果作为新候选，基准图由用户选定。当前 MiniMax 接入支持人物参考图，场景弹窗会提示按文字设定生成。

可以在 Agent 对话里分别试不同的拍法。例如先说「生成第3镜分镜图：远景交代整条雨巷」，再说「生成第3镜分镜图：特写脚踩过积水」。等任务完成后，在分镜表看候选并确认要用的画面。需要同时修改镜头文字设定时，可以请 Agent 提出改动并确认应用。

也可以在 Agent 对话里说「纠正第1镜：面容自然一点，颜色柔和一点」，出图后告诉 Agent 是否满意。要保留做法，再明确提出：

- **偏好**：「满意第1镜，记住为本项目偏好」。可指定仅此素材、本项目同类图或所有个人项目的同类图。已确认的偏好会用于相应范围内后续出图。
- **配方**：确认满意后说「保存第1镜为配方《人物柔光》」，也可以在指令末尾补上要复用的要求，如「：人物形象自然，光线 {{lighting}}」。工作台的「资产库」和个人项目侧栏都有「创作配方」入口，可查看已有版本并编辑为新版本。个人配方可跨个人项目复用，在同类图片的「再生成一版」里选用、填写参数。

历史任务保留实际使用的规则和配方版本。一次纠正默认作用于选中的结果；保存到更广的范围由用户明确选择。见[实现与验收记录](archive/image-learning.md)。

## 团队项目

在首页「团队管理」创建团队、接受邀请或进入团队项目。发邀请前，请让对方先注册，再填写对方的注册邮箱。历史上发给未注册邮箱的邀请会在该邮箱注册时撤销，需要管理员重新发送。团队项目共享创作进度和产物，个人项目保持私有。只读成员可审阅；有编辑权限的成员可编辑内容和提交任务。成员退出后，已提交任务仍可为项目继续执行，原成员失去访问权限。个人 Agent 和图片偏好入口仅用于个人项目。角色与权限细节见[团队实现记录](archive/backend-phase10-team-management.md)。
