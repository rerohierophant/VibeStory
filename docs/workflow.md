# 创作流程

VibeStory 的工作单位是项目、分集和镜头。页面上的操作和 [前端类型](../apps/web/src/lib/types.ts)是当前交互规格；遇到差异以页面为准。

## 从正文到视频

1. **准备正文。** 新建项目和分集，粘贴已有正文。也可以在项目概览上传整稿，由服务端生成分集草案，审阅后确认建集。
2. **拆镜和确认。** 在故事／分镜工作区提交拆镜，编辑画面、景别、运镜、台词与时长。覆盖已有镜头须明确确认。确认后的镜头可以提交分镜出图。
3. **管理参考素材与出图。** 人物和场景可上传或生成多个版本，切换当前基准。分镜可逐镜或按集提交，每镜独立显示受理、复用或阻塞。每张候选记录提交时的人物／场景版本。
4. **选帧和生成视频。** 从镜头候选中选定首帧，提交单镜或按集视频生成。换图后可再提交一版；历史视频保留原首帧。批次有结局只代表每个成员均已结算，成功、失败、未知和阻塞需分别查看。

## 并排比较分镜方案

在「分镜出图方案」选择一组已确认镜头，为它们建立不同画面方案。各方案保存独立修订并生成各自候选。可只重出方案里的指定镜头，其余沿用旧结果。对比后，预览并确认采纳一镜或一组镜头的参数和图；未采纳的候选留在方案里。见[方案实现记录](archive/creative-variants-plan.md)。

## Agent 对话

个人项目可从右侧 Agent 对话操作当前工作区。可以先在对话里发起拆镜，到分镜页确认和提交出图，再回对话继续。页面和 Agent 从同一任务与批次读取进度；切换集、正文或镜头版本后，旧授权和草稿受服务端范围与版本校验。

每集可用主会话、剧本子会话和分镜子会话。主 Agent 可读取状态、调用业务工具或委派创作步骤；子 Agent 提交可审阅的草稿。应用草稿、覆盖镜头、选首帧和发起视频仍有各自的显式入口。已有分集时可直接进入单集创作。Codex 中的独立 MCP 入口见 [README](../README.md#架构与工程)。

## 图片纠正、偏好与配方

个人项目在分镜、人物和场景图片上提供「纠正与偏好」。选一张已完成的生成结果，说明本次怎么改，生成新候选并比较。也可在对话中说「纠正第 1 镜：面容自然一点，颜色柔和一点」。任务完成后，用户可明确标记满意或不满意。

- **偏好**：满意后可编辑要保留的文字规则，选仅此素材、本项目同类图或所有个人项目的同类图。启用的偏好影响后续普通出图、批次和方案出图；可停用或重新启用。
- **配方**：满意后可命名并保存一套做法，用 `{{lighting}}` 等文字槽位留出变量。复用时选择配方版本，绑定当前项目的同类素材并填参，再提交生成。编辑生成新版本。

历史任务保留实际使用的规则和配方版本。一次纠正默认作用于选中的结果；保存到更广的范围由用户明确选择。见[实现与验收记录](archive/image-learning.md)。

## 团队项目

在首页「团队管理」创建团队、接受邀请或进入团队项目。团队项目共享创作进度和产物，个人项目保持私有。只读成员可审阅；有编辑权限的成员可编辑内容和提交任务。成员退出后，已提交任务仍可为项目继续执行，原成员失去访问权限。个人 Agent 和图片偏好入口仅用于个人项目。角色与权限细节见[团队实现记录](archive/backend-phase10-team-management.md)。
